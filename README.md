# SquidChat

SquidChat is a Fabric mod for Minecraft 26.1.2 that provides the following enhancements to the Minecraft chat interface:

* Move and resize the chat window
* Provide an audible alert when a chat message is received
* Set a keybind to show/hide the chat window

## Development

- Requires Java 25 for the Gradle toolchain
- Uses the unobfuscated Fabric 26.1 toolchain with official Mojang names
- Build with `./gradlew build`
- Launch a dev client with `./gradlew runClient`
